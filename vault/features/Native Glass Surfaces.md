# Native Glass Surfaces

Status: shipped
Summary: Translucent "liquid glass" pills and bars used for the Native style's floating controls.

## Details
`src/components/native/glass.tsx`: translucent fill, 0.5px border and inset highlight from the theme tokens; the floating variant adds an `expo-blur` BlurView and a drop shadow. Used by the tab bar, the Home avatar, the Portfolio Edit pill, the Goals add pill and the Holding back/more pills.
