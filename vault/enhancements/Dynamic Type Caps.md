# Dynamic Type Caps

Status: planned
Summary: Scale text with the system text size, with per-role caps.

## Notes
Design Document §7: Body, Secondary, Caption and Data scale 1:1 up to AX5; Title and Heading scale to 1.6×; Hero and Display cap at 1.3× and then abbreviate ($1.28M). At Large and above, the Editorial tab bar shows labels, plinth captions move above values and Provenance goes single-column. No `maxFontSizeMultiplier` or scaling caps exist in the code yet. Applies app-wide rather than to one page.
