# Digit Drift Animation

Status: planned
Summary: Animate changing numbers digit by digit instead of swapping them instantly.

## Notes
Design Document §5: each digit that changes cross-fades while drifting 24px (up for an increase, down for a decrease); 220 ms on the Drift curve; unchanged digits stay still; never count up. Applies to the Home hero, the holding chart scrub header and the add-holding live preview line.
